# My-Portfolio

A modern, responsive portfolio website showcasing my skills, projects, and services as a Full Stack Developer. Built with cutting-edge web technologies and featuring a sleek, professional design.

## ✨ Features

### 🎯 Core Sections
- **Hero Section** - Dynamic typing animation with professional introduction
- **About Me** - Personal background, education, and professional summary
- **Skills** - Animated progress bars showcasing technical expertise
- **Resume** - Education, experience, and graduation project details
- **Portfolio** - Filterable project gallery with three categories
- **Services** - Front-end, Back-end, and Full Stack development offerings
- **Contact** - Contact form and social media links

### 🛠️ Technical Highlights
- **Responsive Design** - Mobile-first approach with Bootstrap
- **Smooth Animations** - AOS (Animate On Scroll) library integration
- **Interactive Portfolio** - Isotope filtering for project categories
- **Lightbox Gallery** - GLightbox for project image previews
- **Typewriter Effect** - Typed.js for dynamic text animation
- **Counter Animation** - PureCounter for statistics display
- **Contact Form** - PHP email integration with validation

## 🎨 Design & UX

- **Modern Aesthetic** - Clean, professional layout with strategic color scheme
- **User-Friendly Navigation** - Fixed sidebar with smooth scrolling
- **Visual Hierarchy** - Clear section organization and typography
- **Interactive Elements** - Hover effects and engaging animations
- **Professional Imagery** - High-quality photos and project screenshots

## 🛠️ Technologies Used

### Frontend
- **HTML5** - Semantic markup and structure
- **CSS3** - Custom styling with CSS variables and animations
- **Bootstrap 5** - Responsive grid system and components
- **JavaScript** - Interactive functionality and DOM manipulation

### Libraries & Frameworks
- **AOS** - Scroll animations
- **Typed.js** - Typewriter effects
- **PureCounter** - Animated counters
- **GLightbox** - Image lightbox gallery
- **Isotope** - Filterable portfolio layout
- **Swiper** - Touch slider (if used)
- **Waypoints** - Scroll trigger points
